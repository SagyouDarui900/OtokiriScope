# OtokiriScope (音きりスコープ)

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)
[![Platform: Windows](https://img.shields.io/badge/Platform-Windows%2064--bit-informational.svg)]()
[![Format: VST3](https://img.shields.io/badge/Format-VST3-success.svg)]()

**OtokiriScope** は、ステレオ音声信号から定位（左右）、周波数帯域、奥行き（Mid/Side比率）を指定して抽出または消去する Windows 64-bit 向け VST3 プラグインです。

本プラグインは、2009年に公開された音声分離ソフトウェア「音きりす V1.0」（(C) 2009 TODAKEN）の2画面操作体系をもとに、DAW（Digital Audio Workstation）環境で動作するVST3プラグインとして新規に実装したものです。

4096点短時間フーリエ変換（STFT）による複素スペクトルマスキングと周波数平滑化フィルターにより、耳コピ、特定楽器の抽出、ボーカル消去（カラオケ化）などをリアルタイムに行えます。

---

## 主な機能

- **2画面スペクトログラム解析**
  - **定位スクリーン (L - Center - R)**: 左右の振幅差から推定した定位と周波数ごとのエネルギー分布をヒートマップ表示します。
  - **奥行きスクリーン (F - B)**: Mid 信号と Side 信号のエネルギー比から推定した音の拡散度（Direct/Front 〜 Diffuse/Back）を表示します。
- **STFT 複素スペクトルマスキング**
  - 4096点 FFT、75% オーバーラップ（ホップサイズ 1024サンプル、Hann窓）によるオーバーラップ加算合成（OLA）。
  - **3タップ周波数平滑化**: 周波数ビン間の利得差を緩和し、スペクトル編集時に生じやすいミュージカルノイズ（不連続な残留音）を抑制します。
  - **エルミート（Smoothstep）補間**: 選択枠の境界で利得を滑らかに減衰させ、急峻なカットに伴う音質劣化を低減します。
  - **端部バイパス処理**: 選択幅を最大にした際に端部が減衰しないよう、全帯域・全定位でのバイパス処理を備えています。
  - **音量平滑化**: 出力音量スライダーの変更時に線形補間を適用し、ジッパーノイズ（急激な音量変化によるプチノイズ）を防止します。
- **プリセット & A/B 比較**
  - ボーカル抽出（Center）、ボーカル消去（反転）、ベース、ギター（L/R）、ドラム/スネア、高音アルペジオなどのプリセットを切り替え可能です。
  - Slot A / Slot B の 2 つの設定を切り替えて比較試聴できます。
- **マウス操作**
  - 矩形の内側ドラッグで位置移動、外周ドラッグでサイズを変更します。
  - ダブルクリックまたは各最大化ボタンで、全範囲最大化と直前状態を相互に切り替えます。
  - **Shift キー併用**: 移動速度が 0.2 倍速になり、微調整が行えます。
- **パフォーマンス設計**
  - ヒートマップの色変換に 256 要素の事前計算ルックアップテーブル（LUT）を使用し、描画処理の負荷を低減しています。
  - 「ビジュアルなし」を有効にすると、スペクトログラム描画を停止して負荷を低減できます。
- **DAW連携**
  - ホスト DAW のテンポ (BPM)、拍子、タイムコード、小節数、再生状態を表示します。
  - マウスによるパラメータ操作時にオートメーションジェスチャー（開始・終了）を発行します。

## アルゴリズムの特性と制限事項

本プラグインは、左右チャンネルの振幅差から定位を、Mid（L+R）と Side（L-R）の振幅比から奥行き（拡散度）を推定しています。
位相差や相互相関を用いた解析は行っていないため、以下の音源では意図した分離が得られない場合があります。

- 左右で位相が反転しているトラック
- 広がりを持つステレオリバーブ成分（アンビエンス）が多く含まれるトラック
- センターに配置された複数の楽器の帯域が重複している場合

## 動作環境

- **OS**: Windows 10 / 11 (64-bit)
- **形式**: VST3 (64-bit)
- **対応サンプリングレート**: 44,100 Hz / 48,000 Hz / 88,200 Hz / 96,000 Hz 等
- **入出力**: ステレオ入出力（モノラルトラックへのステレオダウンミックス出力に対応）
- **動作確認済み DAW**: Cockos REAPER 7.x（その他の VST3 対応ホストでの動作は未確認です）

## 画面構成と操作

```text
+------------------------------------------------------------------------+
| OtokiriScope                                                           |
+------------------------------------+-----------------------------------+
|            [ 定位スクリーン ]      |         [ 奥行きスクリーン ]      |
|  20k +---------------------------+ |  20k +--------------------------+ |
|  10k |                           | |  10k |                          | |
|   1k |    [ 抽出エリア矩形 ]     | |   1k |    [ 抽出エリア矩形 ]    | |
|  100 |                           | |  100 |                          | |
|   20 +---------------------------+ |   20 +--------------------------+ |
|      L            C            R   |      F            50%         B   |
+------------------------------------+-----------------------------------+
| 周波数: 200 Hz - 8.0 kHz | 定位: Center   | 奥行: 50% (幅 100%)        |
+------------------------------------------------------------------------+
| [定位最大化]  [定位中央]  [周波数最大化]         [奥行最大化]          |
|                                                                        |
| 抽出強度   [======== ]    再生音量   [==========]   [ ] 定位固定       |
| 境界滑らか [==       ]    定位スケール [=====     ]   [ ] 周波数固定     |
| 残響抑制   [         ]    カラースケール [=====   ]   [ ] 抽出エリア反転 |
|                                                     [ ] ビジュアルなし |
| 44100 Hz   [先頭へ]  [再生/停止]  [Slot A]   120.0 BPM (4/4)  再生中    |
+------------------------------------------------------------------------+
```

### 1. スクリーン操作
- **抽出エリアの移動**: 選択枠の内側を左ドラッグします。
- **抽出エリアのリサイズ**: 選択枠の四辺または四隅を左ドラッグします。
- **微調整**: **Shift キー** を押しながらドラッグすると、変化速度が 0.2 倍になります。
- **最大化 / 復元**:
  - スクリーン内をダブルクリックすると、最大化と直前サイズの復元が切り替わります。
  - 下部の `[定位最大化]` `[定位中央]` `[周波数最大化]` `[奥行最大化]` ボタンでも同様の操作が可能です。

### 2. スライダー設定
| スライダー | 説明 |
|---|---|
| **再生音量** | プラグインの最終出力利得（0.0 〜 1.0）を調整します。 |
| **抽出強度** | 抽出効果の深さを調整します。1.0 で完全適用、0.0 で原音通過になります。 |
| **境界の滑らかさ** | マスク境界の減衰幅を調整し、音の途切れを緩和します。 |
| **定位スケール** | 定位パラメータ（未使用の内部予約パラメータです）。 |
| **カラースケール** | ヒートマップの輝度感度を調整します。 |
| **残響抑制** | 奥行き Back 側の拡散成分を減衰させます。 |

### 3. チェックボックス
- **定位固定**: 定位方向（横方向）の移動と幅変更を制限します。
- **周波数固定**: 周波数方向（縦方向）の移動と帯域幅変更を制限します。
- **抽出エリア反転**: 選択枠内を減衰させ、枠外の音を通過させます（ボーカルキャンセル等）。
- **ビジュアルなし**: スペクトログラムの描画更新を停止し、CPU 負荷を抑えます。

### 4. トランスポート表示
- 下部の `[先頭へ]` `[再生 / 停止]` ボタンはホスト状態の表示用です。プラグイン UI からホスト DAW の再生・停止は制御できません。操作は DAW 側で行ってください。

## ビルド手順

### 必要な環境
- Windows 10 / 11 (64-bit)
- Visual Studio 2022（「C++ によるデスクトップ開発」）
- CMake 3.22 以上
- Git

### コマンド例

```powershell
# 1. リポジトリのクローン
git clone https://github.com/SagyouDarui900/OtokiriScope.git
cd OtokiriScope

# 2. CMake プロジェクト生成 (JUCE 8.0.10 は自動取得されます)
cmake -B build -G "Visual Studio 17 2022" -A x64

# 3. リリースビルド
cmake --build build --config Release --target OtokiriScope_VST3
```

ビルド完了後、`build/OtokiriScope_artefacts/Release/VST3/OtokiriScope.vst3` に成果物が生成されます。
（管理者権限で実行した場合は自動的に `C:\Program Files\Common Files\VST3\OtokiriScope.vst3` へコピーされます）
