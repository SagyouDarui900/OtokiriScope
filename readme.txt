□□【初めに】□□

　　「音きりす」は、ステレオのWAVEファイルから左右の定位や周波数などで範囲を絞っ
　て音を抽出するプログラムです。
　　特定の範囲にある音を聞き取りやすくしたり、逆にマスクしたりすることができます。
　　視覚的な操作でリアルタイムに音を再生しながら効果を確認して、処理結果をWAVE
　ファイルとして保存します。


□□【動作環境】□□

　動作確認済みＯＳ　：Windows XP / Vista / 7

　対応ファイル　：WAVEファイル（16bit ステレオ PCMフォーマット）


□□【インストール／アンインストール】□□

　　適当なフォルダへ全てのファイルをコピーしてください。

　　アンインストールはファイルを削除してください。
　　レジストリは使用していませんが、以下のフォルダに設定ファイルがあります。不要
　　であれば削除してください。

　　《XPの場合》
　　　C:\Documents and Settings\ユーザー名\Local Settings\Application Data\Otokiris

　　《Vista / 7の場合》
　　　C:\Users\ユーザー名\AppData\Local\Otokiris


□□【使用方法】□□

　　Otokiris.exe を起動してください。

　　詳細はヘルプファイル（OtokirisHelp.pdf）を見てください。

　　※ヘルプファイルを表示するには「Adobe Reader」が必要です。
